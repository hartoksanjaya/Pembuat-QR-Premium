🔐 Kebijakan Privasi

📅 Terakhir Diperbarui: 10 Mei 2026 📋 Versi: 1.0 🌐 QR Studio Pro

1. Pendahuluan

Selamat datang di QR Studio Pro ("Aplikasi", "kami", atau "milik kami"). Kami menghargai privasi Anda dan berkomitmen untuk melindungi data pribadi Anda.

Kebijakan Privasi ini menjelaskan bagaimana kami menangani informasi Anda saat Anda menggunakan aplikasi pembuat QR Code berbasis web kami.

Dengan mengakses atau menggunakan QR Studio Pro, Anda menyetujui praktik yang dijelaskan dalam kebijakan ini.

2. Informasi yang Kami Kumpulkan

🚫 Informasi yang TIDAK Kami Kumpulkan

Aplikasi kami dirancang dengan prinsip privacy-first. Kami tidak:

  • Mengumpulkan nama, email, nomor telepon, atau identitas pribadi Anda
  • Menyimpan URL, teks, atau konten QR Code yang Anda buat di server kami
  • Mengunggah atau menyimpan gambar/logo yang Anda tambahkan ke QR Code
  • Melacak lokasi geografis atau alamat IP Anda secara permanen
  • Mengakses kontak, galeri, atau data perangkat Anda tanpa izin eksplisit

✅ Informasi yang Diproses Secara Lokal (Client-Side)

Semua pemrosesan terjadi sepenuhnya di perangkat Anda melalui browser:

Data Tujuan Penyimpanan
Teks/URL Input Generate QR Code 🔒 Lokal Only
Gambar/Logo Overlay pada QR 🔒 Data URL (Memori)
Preferensi UI Kenyamanan pengguna 🗄️ localStorage (Opsional)
Riwayat QR Akses cepat 🗄️ localStorage (Opsional)

💡 localStorage hanya tersimpan di browser Anda. Data ini tidak dapat diakses oleh kami dan dapat dihapus kapan saja via pengaturan browser.

3. Bagaimana Kami Menggunakan Informasi

Karena aplikasi berjalan sepenuhnya di sisi klien, penggunaan data sangat terbatas:

┌─────────────────────────────────────┐ │ INPUT ANDA → [Browser Anda] → QR │ │ ↓ │ │ TIDAK ADA DATA KE SERVER │ └─────────────────────────────────────┘

Data hanya digunakan untuk:

  • 🎨 Generate QR Code: Mengubah teks/URL menjadi kode QR yang dapat discan
  • 🖼️ Kustomisasi Visual: Menerapkan warna, bentuk, dan logo pilihan Anda
  • 💾 Pengalaman Pengguna: Menyimpan preferensi opsional untuk sesi berikutnya
  • 📥 Unduhan: Memungkinkan Anda mengunduh hasil QR sebagai file PNG/SVG

4. Teknologi Pihak Ketiga

Aplikasi menggunakan library open-source via CDN untuk fungsionalitas inti:

Library Tujuan Kebijakan
QR Code Styling Generate QR dengan kustomisasi MIT License ✅
Google Fonts (Inter) Tipografi konsisten Google Privacy

⚠️ Catatan CDN: Saat pertama memuat, browser mungkin menghubungi server CDN. Permintaan ini hanya mencakup IP dan user-agent standar — bukan konten QR atau data pribadi Anda.

5. Keamanan Data

  • 🔐 Pemrosesan Lokal: Semua logika berjalan di browser Anda, tidak ada data dikirim ke backend
  • 🛡️ HTTPS: Aplikasi dihosting dengan enkripsi SSL/TLS untuk integritas kode
  • 🧹 Tanpa Logging: Kami tidak mencatat aktivitas, input, atau unduhan pengguna
  • 🔄 Update Berkala: Library pihak ketiga diperbarui untuk menambal kerentanan

6. Hak Pengguna

Anda memiliki kendali penuh atas data Anda:

Hak Cara Melaksanakan
🗑️ Hapus Riwayat Klik "Hapus Semua" atau bersihkan localStorage via pengaturan browser

7. Privasi Anak-Anak

QR Studio Pro tidak secara khusus ditujukan untuk anak di bawah 13 tahun. Namun, karena:

  • ✅ Tidak mengumpulkan data pribadi apa pun
  • ✅ Tidak ada akun, login, atau pelacakan pengguna
  • ✅ Semua pemrosesan bersifat lokal dan anonim

Aplikasi ini aman digunakan oleh segala usia untuk tujuan edukasi atau pribadi. Orang tua tetap disarankan untuk mengawasi aktivitas online anak-anak.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Perubahan akan:

  • 📢 Diumumkan melalui pembaruan versi di aplikasi
  • 📅 Dicantumkan tanggal "Terakhir Diperbarui" di bagian atas

Penggunaan berkelanjutan aplikasi setelah perubahan berlaku merupakan penerimaan Anda terhadap kebijakan yang diperbarui.

10. Persetujuan

Dengan menggunakan QR Studio Pro, Anda menyatakan bahwa Anda:

  1. Telah membaca dan memahami Kebijakan Privasi ini
  2. Menyetujui pemrosesan data secara lokal seperti yang dijelaskan
  3. Memahami bahwa Anda bertanggung jawab atas konten QR Code yang Anda buat (pastikan tidak melanggar hak cipta atau kebijakan pihak ketiga)

🔐 Ringkasan Privasi: QR Studio Pro tidak mengumpulkan, menyimpan, atau membagikan data pribadi Anda — semua pemrosesan terjadi secara lokal di perangkat Anda, dan Anda memiliki kendali penuh atas konten yang Anda buat.

💡 Tips Privasi Tambahan

Gunakan Mode Penyamaran: Buka aplikasi di tab Incognito/Private untuk sesi tanpa jejak di localStorage.
Bersihkan Cache Berkala: Hapus localStorage via chrome://settings/siteData jika ingin menghapus semua preferensi.
Self-Host untuk Privasi Maksimal: Unduh kode sumber dan jalankan secara lokal (file://) untuk menghilangkan semua permintaan CDN.
